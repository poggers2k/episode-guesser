# איזה פרק?

משחק ניחוש: קוראים תקציר של פרק ומנחשים מאיזו עונה ומאיזה פרק הוא.
אפליקציית ווב שאפשר להתקין בטלפון (PWA). היא עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה.

## מבנה

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html`, `styles.css`, `app.js` | האפליקציה |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה בטלפון ועבודה בלי אינטרנט |
| `data/catalog.json` | רשימת הסדרות שהאפליקציה מציגה (נבנית אוטומטית) |
| `data/series/<id>.json` | כל הפרקים של סדרה: `[עונה, פרק, שם באנגלית, תקציר]` |
| `tools/` | סקריפטים להוספת סדרות ולבדיקה מקומית |
| `work/` | חומרי עזר מ-TVmaze וטיוטות. **לא מתפרסם** (ב-`.gitignore`) |

האפליקציה מורידה את `data/catalog.json` בכל פתיחה, אז סדרה שנוספה לשרת מופיעה אצל כולם בלי עדכון גרסה.

## הוספת סדרה

הכי פשוט: לבקש מ-Claude Code "תוסיף את הסדרה X". זה מה שהוא עושה:

1. מוריד את רשימת הפרקים:
   `.\tools\fetch-episodes.ps1 -Id sopranos -He "הסופרנוס" -Query "The Sopranos" -Tint "#8A6A3B"`
   (אם החיפוש מוצא סדרה אחרת, מוסיפים `-TvmazeId` עם המספר מ-tvmaze.com)
2. כותב תקציר מקורי בעברית לכל פרק, לקובץ לכל עונה: `work/out/<id>/s01.json` = `{"1":"תקציר","2":"..."}`.
   תקציר ריק `""` = פרק שלא נשאל עליו (נשאר בספירת הפרקים).
3. מוסיף את הסדרה ל-`tools/genres.json` (`sitcom` או `drama`).
4. בודק ומאחד: `.\tools\merge-series.ps1 -Id <id>`. הסקריפט כותב את `data/series/<id>.json` ובונה מחדש את `data/catalog.json`.
5. מעדכן את התיקייה `upload-to-github` ומעלים את `data` לאתר (ראו "עדכון אחרי הוספת סדרה" למטה).

כללי התקצירים: עברית, משפט או שניים, ניסוח מקורי ולא תרגום של התקציר מ-TVmaze, בלי שם הפרק ובלי מספרים, עם פרט אחד לפחות שמזהה את הפרק.

## בדיקה מקומית

`.\tools\serve.ps1` ואז לפתוח http://localhost:8765

## העלאה לאוויר (GitHub Pages, חינם)

המאגר: `episode-guesser` (ציבורי). הכתובת: `https://<user>.github.io/episode-guesser/`.

העלאה ראשונה, דרך האתר של GitHub:
1. github.com/new: שם `episode-guesser`, Public, בלי README. Create repository.
2. בעמוד המאגר הריק: "uploading an existing file".
3. פותחים את התיקייה `upload-to-github` ובוחרים את **כל מה שבתוכה** (Ctrl+A, כולל התיקיות), גוררים לחלון. Commit changes.
   (הקבצים `.gitignore` ו-`.nojekyll` מוסתרים לפעמים בסייר. אם הם לא עלו, זה לא נורא.)
4. Settings → Pages → Source: Deploy from a branch, Branch: `main`, תיקייה `/ (root)`, Save.
5. אחרי דקה-שתיים האתר באוויר. בטלפון: "הוספה למסך הבית".

עדכון אחרי הוספת סדרה: מעלים שוב (Add file → Upload files) רק את `data/catalog.json` ואת `data/series/<id>.json` החדש, לתיקייה `data`. GitHub מחליף קבצים קיימים בשם זהה. כדי שהם יגיעו למקום הנכון, גוררים את התיקייה `data` כולה מתוך `upload-to-github`.

## בהמשך: חנויות האפליקציות

- **Google Play**: אפשר לארוז את אותו אתר כאפליקציה (Trusted Web Activity, למשל עם PWABuilder.com) או עם Capacitor. חשבון מפתח עולה 25$ חד-פעמי.
- **App Store**: עוטפים עם Capacitor. צריך מק או שירות בנייה בענן, וחשבון מפתח של אפל ב-99$ לשנה.
  אפל דוחה לפעמים אפליקציות שהן רק אתר עטוף (סעיף 4.2), אז כדאי להוסיף לפני כן משהו שמרגיש אפליקטיבי, למשל רטט, התראות יומיות או מצב יומי.
- בעטיפה מגדירים `window.WE_DATA_BASE` לכתובת המלאה של תיקיית `data/` באתר, כדי שהאפליקציה תמשיך לקבל סדרות חדשות מהשרת.
- **שמות הסדרות**: המשחק משתמש בשמות בלבד, בלי לוגואים ותמונות, ומציין שאינו קשור לבעלי הזכויות. החנויות בודקות קניין רוחני (אפל סעיף 5.2), אז אין להוסיף תמונות או לוגואים רשמיים.
